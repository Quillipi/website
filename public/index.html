How it works

A notebook is a set of pages for one project. You write in it, Claude writes in it, and nothing changes without a record.

  1. 1

    Write it down once

    Start a notebook in one click, or ask Claude to make one. Put in what matters: the idea, the decisions, the plan, the why behind them. Folders keep a big project tidy.

    It's a normal editor. Headings, lists, tables, checklists, images and drawings.

  2. 2

    Claude reads it whenever you ask

    Connect Quillipi to Claude once. After that, a new chat needs one line, like "read my launch plan", and Claude knows the whole project. No pasting.

    It reads a short map first and then only what it needs, so long notebooks stay cheap to use.

  3. 3

    You see every change, and keep the ones you want

    Claude edits paragraph by paragraph, never the whole page. Its changes show in the margin until they're committed. Every commit says who made it, and any commit can be undone.

    If Claude tries to delete something big, it waits for you to approve it.

Built so you can trust what's in it

  • Every paragraph has its own ID

    Claude changes the exact paragraph it means to, by ID, and only after reading it. Nothing else on the page moves.

  • Real Git history

    Every change is a Git commit, kept in a private repo in your GitHub. Same history everywhere, readable with any Git tool.

  • Your words win

    If you and Claude change the same paragraph at the same time, your version is the one that stays.

  • Undo any commit

    Took a wrong turn last Tuesday? Undo that one commit. Later work stays where it is.

  • Instructions for each notebook

    Write once how you want Claude to work there. It gets them before anything else in the notebook, and no AI can change them.

  • On your phone, laptop off

    Open it in any browser or install it as an app. Claude on your phone reads the same notebook.

  • One click, new notebook

    A notebook for every idea, project or book. Claude can make one from a chat when you ask.

  • Always on, nothing to run

    It lives in your own Cloudflare account. No server to look after, no laptop that has to stay awake.

Yours, start to finish

Quillipi doesn't hold your notes on my servers. Your copy runs in your accounts, and you can walk away with everything.

  • Runs in your Cloudflare account. Cloudflare's free plan is enough.
  • History in your GitHub. Every notebook is a private repo in an organization you own.
  • Plain Markdown files. Open them in any editor, today or in ten years.
  • Source-available. The code is public: read it, run it, improve it.
  • Updates when you say so. Your copy opens an issue when a new version is out. One button updates it, and reverting that one commit undoes it.

Questions

Is it really free?

Yes, for one person. Quillipi runs in your own Cloudflare account, and Cloudflare's free plan is enough for it, so there's nothing to pay me or them. The code is public and source-available, under the PolyForm Shield license. Teams will pay once team features exist.

Can you read my notebooks?

No. Your copy of Quillipi runs in your Cloudflare account and keeps its history in your GitHub. Nothing passes through me.

Do I need to know Cloudflare or GitHub?

You need a free account on each. The setup page walks you through every step and tells you what to press on each page, and you come back to Quillipi by yourself. No terminal.

What does Claude actually do with it?

At the start of a chat it reads a short map of the notebook, then only the pages it needs. It edits paragraphs by their IDs, commits its own changes with a message saying what it did, and never commits yours. Big deletions wait for your approval.

Which AI apps work with it?

Claude today: claude.ai, the desktop app, the phone apps and Claude Code. Quillipi speaks MCP, the open standard these apps use, so ChatGPT, Cursor and VS Code are next. I'll list them here once I've tried each one.

What if I stop using it?

Your notebooks are Markdown files in a Git repo you own. Take them anywhere, open them with anything.

Who makes this?

Me, Karan. I'm building it on my own, out in the open. If something breaks or you want something, open an issue on GitHub or email hello@quillipi.app.
