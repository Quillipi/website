Setup guide

Set up Quillipi, step by step

Quillipi runs in your own free Cloudflare account and keeps its history in your own GitHub. This page takes you there one step at a time. Tick each step when it's done.

About 20 minutes if you're new to GitHub and Cloudflare, less if you have the accounts. Free, and no terminal.

0 of 5 steps done

This page remembers your ticks in this browser, so you can go to GitHub or Cloudflare and come back.

Before you start

  • Use a computer. A phone works for Quillipi later, but setting up is easier on a big screen.
  • You need three free accounts: GitHub, Cloudflare and Claude. Already have one? Skip its step.
  • Make a new password for each. Cloudflare refuses a password that has ever leaked anywhere. A password manager makes this easy.
  • Links open in a new tab. This tab stays here. Come back to it after each step.

  1. Make a GitHub account about 3 minutes

    GitHub keeps every notebook's history, in private repositories that only you can see.

    1. Open GitHub's sign-up page.
    2. Type your email and a new password.
    3. Pick a username. Nobody else on GitHub can have it, so if it says it's not available, add a word or a number.
    4. Press Create account. GitHub may ask you to solve a small puzzle, then it emails you a code. Type the code in.
    5. Come back to this tab.

    Step 3 needs it. It stays in this browser and is never sent anywhere.

    "Too many requests"? GitHub is checking usernames too fast. Wait a minute, then reload the page.

  2. Make a Cloudflare account about 3 minutes

    Cloudflare runs your Quillipi, always on, even when your computer is off. Its free plan is enough.

    1. Open Cloudflare's sign-up page. Use this link: signing up from the Deploy button can stop with "Invalid redirect_uri".
    2. Type your email and a new password. If Cloudflare says the password was leaked in a data breach, choose a different one. It means that password appears in a leaked list somewhere, not that anything happened to your account.
    3. Tick Verify you are human, then press Sign up.
    4. Cloudflare emails you a link. Open it on this computer if you can.
    5. Cloudflare then shows its own home page with lots of choices. Don't create anything there. Come back to this tab.

    Opened the email on your phone? A "Verify your account" box stays on the computer and doesn't close. Reload the Cloudflare tab (F5) and it goes away.

  3. Put Quillipi in your Cloudflare about 5 minutes

    Cloudflare makes a private copy of Quillipi in your GitHub and runs it. You fill in one box.

    Deploy to Cloudflare

    1. Press Deploy to Cloudflare above. Cloudflare opens Set up your application.
    2. Under Git account, press New GitHub connection. Sign in with your GitHub account, then press Install & Authorize.
    3. Back in the form, check that Create private Git repository is ticked. Project name says quillipi. It becomes part of your address, so change it if you like.
    4. Scroll down to GITHUB_USER_LOGIN and type your GitHub username: your GitHub username. Only this GitHub account can finish the setup and use your Quillipi.
    5. Leave everything else as it is, and press Deploy.
    6. Wait about a minute while Cloudflare builds it. When the last line says Success! Build completed., look a few lines up for your address. It starts with https:// and ends with .workers.dev.

    Landed on "Select a repository" with "No Git repositories found"? Nothing is wrong. After connecting GitHub, Cloudflare sometimes forgets where you came from. Close that tab, come back here and press Deploy to Cloudflare again. The form now shows your GitHub account.

    Open my Quillipi

    Paste it here, or into your browser's address bar. A search box won't find it.

  4. Finish in your Quillipi about 5 minutes

    From here your own Quillipi guides you. Its setup page shows one thing at a time and ticks each one off.

    1. An organization for your notebooks. A free GitHub organization that holds only your notebooks. Its name must be new on GitHub too, so if it's taken, add a word.
    2. Quillipi's GitHub App. One click makes it, one more installs it in that organization.
    3. Sign in with GitHub. Then you land on your Quillipi's Home.

  5. Turn on updates about 1 minute

    So your Quillipi tells you when a new version is out, and updates with one button when you say so.

    1. On your Quillipi's Home, Get started begins with Turn on updates. Press Add the file on GitHub: GitHub opens with the file already filled in.
    2. On GitHub, press Commit changes…, then Commit changes again, and come back.
    3. Cloudflare puts your Quillipi up again with the file, and in a minute or two the step ticks itself.

    Why can't Cloudflare add it? Its GitHub connection may not add workflow files, the kind that runs on a schedule, so this one file is yours to add. GitHub says the page isn't found? Open "GitHub says the page isn't found?" under the button: it gives the file's name and text to add by hand.

  6. Connect Claude and start a notebook about 3 minutes

    Connect once, and every Claude chat can read and write your notebooks: on the web, the desktop app, the phone and Claude Code. Claude's free plan works too.

    1. On your Quillipi's Home, Get started shows how to add Quillipi to Claude, with your address ready to copy.
    2. When Claude asks, press Connect, then Continue with GitHub.
    3. Make your first notebook: press New notebook on Home, or ask Claude in any chat, for example "Make a Quillipi notebook called garden plan and write a plan in it."

    Your Claude's Settings show Connectors, not Plugins? Add Quillipi there instead: Connectors, then Add custom connector.

You're set up.

Your notebooks live in your Cloudflare and your GitHub. Start any chat with "read my notebook" and Claude picks up where you left off.

Stuck?

Email hello@quillipi.app and say which step you're on. A screenshot helps. Or open an issue on GitHub.

The screenshots are from November 2026. Cloudflare and GitHub change their pages now and then, so yours may look a little different.
